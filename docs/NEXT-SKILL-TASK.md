# 已完成 Skill 任務：安全切換五大頁籤並開啟既有腳本

## 目標

讓 CODEX 能在 XScript 編輯器內，安全地切換指標、選股、警示、交易與函數五大自繪分類，並從該分類唯一的 `自訂/CODEX/` 開啟使用者指定的既有腳本，不再要求使用者先手動切換。

## 安全邊界

- 優先使用可讀回的 control ID、UIA／MSAA 動作、正式命令、名稱、階層及選取狀態。
- 找不到語意介面時，只能依操作憲法使用當次視窗內的單步、節流、局部相對操作；不得保存或沿用固定螢幕座標。
- 不得建立臨時空白腳本來繞過頁籤切換，也不得猜測 `WM_COMMAND`、快捷鍵或顯示／隱藏內容 pane。
- 切換後必須同時讀回目標分類及其唯一直接子路徑 `自訂/CODEX/`；不一致、缺少或重複時立即停止。
- 開啟既有文件前，必須以完整名稱唯一匹配，並在開啟後讀回腳本名稱、類型與位置；不得搜尋、開啟或修改私人區域內容。
- 所有輸入套用可調速度等級、前景守門、自適應等待及 Windows incident 保存契約。

## 驗收條件

1. 五類各自都有成功、目標不存在、名稱不唯一、CODEX 缺少／重複及錯誤分類測試。
2. 同類與跨類切換皆可重複執行；已在目標類別時不送多餘輸入。
3. 真實 XQ 只用五類 CODEX 測試文件逐類驗證，不接觸私人腳本，不建立臨時路由腳本。
4. Windows 無回應、前景遭遮擋、頁籤晚到或開啟 timeout 時立即停止輸入並保存完整 incident。
5. 更新操作憲法、Skill、Windows 校正指南、README、CHANGELOG、單元測試及 Skill validator；最後完成測試文件清理與桌面收尾。

## 2026-08-02 驗收結果

- 指標、選股、警示、交易與函數五類皆以真實 XQ 3.19.03 完成分類切換、唯一 `自訂/CODEX/` 讀回及指定文件開啟。
- 頁籤位置與文件雙擊點皆由當次局部記憶體截圖重新推導，沒有固定螢幕座標、比例或成功截圖落地。
- 重複執行已開啟的交易文件時，分類切換與文件開啟皆未送出輸入。
- 初次以 Enter 開啟函數文件時發生一次 `document_open_timeout`；流程依憲法停止輸入並保存 incident。視窗健康讀回正常，後續以一次局部截圖雙擊完成復原；未將 timeout 推測成 XQ 錯誤碼、斷網或當機。
- 真實驗證只使用既有 CODEX 文件，未建立測試文件、未搜尋或修改私人腳本。
