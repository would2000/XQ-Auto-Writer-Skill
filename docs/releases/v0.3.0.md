# v0.3.0

發布追蹤：[Issue #7](https://github.com/would2000/XQ-Auto-Writer-Skill/issues/7)

## 重點更新

- 將 XQ Auto Writer 從單純建檔／編譯擴充為指標、選股、警示、函數與自動交易的實際執行、證據擷取及安全復原工具組。
- 完成函數整合測試自動化第 4～9 階段，加入資料邊界矩陣、晚到報告復原、不可變 baseline、慢速桌面韌性、批次續跑與發布候選閘門。
- 導入最高優先的 XQ 操作憲法：私人內容唯讀、CODEX 專區隔離、禁止實單／帳戶操作、全面禁止座標控制並要求任務後桌面復原。

## 新增功能

- 指標原生資料匯出與逐列公式比對。
- 選股策略建立、執行、CSV 擷取、錯誤明細及一鍵管線。
- 警示策略的觸發／不觸發紅綠燈驗證。
- 函數三種回傳型別、Ref／Array、歷史序列、跨頻率、巢狀函數及資料不足整合測試。
- 自動交易歷史回測、五態結果分類、主動中止、checkpoint、唯讀 recovery-status 及報告匯出。
- XSHelp 結構化蒸餾搜尋及官方自動交易／錯誤處理指南。
- RC 介面凍結、私有維護模式、CI 閘門及 `v0.2.0` 升級／byte-level 復原演練。

## 問題修正

- 修正腳本名稱含「錯誤」時可能誤判編譯結果。
- 相容 XSHelp 現行表格型頁面。
- 修正指標重名欄位、警示策略重新選取及回測停用預載欄位等自動化邊界。

## 不相容變更與升級步驟

- 無刻意的不相容公開介面變更。
- 從 `v0.2.0` 升級後，涉及 XQ 建檔或測試的功能必須先在每個對應分類建立並校正唯一的 `自訂/CODEX/` 專區；工具不再接受 `自訂/` 根目錄或座標猜測作替代。

## 已知限制

- 目前只在指標分類讀回唯一 `自訂/CODEX/`；選股、警示、交易及函數分類仍需完成資料夾與正式非座標切換選擇器校正。

- CI 是唯讀 Windows hosted runner，不具登入中的互動式 XQ 桌面；CI Passed 不代表實盤安全、獲利能力或真實 XQ 全矩陣完成。
