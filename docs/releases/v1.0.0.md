# v1.0.0

發布追蹤：[Issue #9](https://github.com/would2000/XQ-Auto-Writer-Skill/issues/9)

## 重點更新

- 正式提供五類 XScript 的逐類基礎來源產生器：指標、選股、警示、函數與自動交易。
- 函數範本可讓指標、選股、警示與自動交易各自建立最小數值函數 caller，不必一次建立所有類型。
- 將發布候選介面升級為 `rc-interface-v2.json`，以 0.3.0 為升級來源、1.0.0 為首次穩定公開承諾。

## 新增功能

- `xq_generate_basic_script.py --script-type <type> --output <new-file.xs>` 產生一份新的 UTF-8 基礎來源，拒絕覆寫既有檔案。
- `--with-function --function-name <已編譯函數名稱>` 可讓指標、選股、警示或自動交易產生呼叫數值函數的版本。
- XQ 3.19.03 已在每個類型限定的 `自訂/CODEX/` 建立並編譯 `CodexBasicDeltaV1`、`CodexBasicIndicatorV1`、`CodexBasicScreenerV1`、`CodexBasicAlertV1`、`CodexBasicAutotradeV1`；五份皆為 0 錯誤、0 警告。

## 問題修正

- 無。

## 不相容變更與升級步驟

- 發布候選檢查的預設凍結檔改為 `release/rc-interface-v2.json`；`rc-interface-v1.json` 保留為 0.x 歷史合約。
- 升級／復原演練的預設來源 tag 改為 `v0.3.0`。
- 產生器只建立來源檔。先編譯函數，再以相同函數名稱編譯各 caller；不要把來源建立成功當作 XQ 執行證據。

## 已知限制

- 五類基礎來源與函數 caller 的通過證據是當次 XQ 編譯；不等於指標已在圖表正確繪值、選股已有預期結果、警示已觸發、自動交易已回測，或任何策略可安全實盤。
- 自動交易基礎 caller 不含 `SetPosition`、帳號設定、下單或回測；所有實盤操作仍受 XQ 操作憲法禁止。
